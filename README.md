## 我怎样工作

**定义问题 → 调研证据 → 提出假设 → 制作原型 → 验证迭代 → 沉淀方法**

从具体问题开始，以可查看、可使用的作品检验判断；在每次交付中积累工具、流程和知识，让下一次工作有更好的起点。

我持续关注三件事：**生产系统、客户获取系统、价值交付系统**。
